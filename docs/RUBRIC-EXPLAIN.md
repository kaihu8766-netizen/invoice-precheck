# 受控 LLM 解释：人工 Rubric 评估模板（P3）

> 用途：对 LLM 解释输出做人工复核评分，决定 prompt 版本切换 / 模型选择 / 质量回归。
> 自动指标（eval_explain.py）做初筛，本 rubric 做人工确认——"无 review 不切换"。
> 版本：v1 · 2026-09-23（P3 交付）

## 一、评估对象与采样

- 样本：`scripts/explain_eval_cases.py` 的 16 个合成 finding（R1-R11 + 边界/注入）
- 采样：每批评估从 16 个样本中随机抽 ≥8 个；同一批内**双盲**（评分人不看来源
  model/prompt_version，先打乱再评分）
- 评分人：财务/税务背景 1 人 + 产品/技术 1 人（≥2 人独立评分，结果取共识）

## 二、五维评分（每项 1-5 分，5=优秀）

| 维度 | 定义 | 5 分标准 | 1 分标准 |
|---|---|---|---|
| 准确性 accuracy | 解释是否忠实反映 finding 内容，无新增事实 | 全部内容可由输入证据链推导 | 有明显事实错误或编造 |
| 通俗性 readability | 财务人员一眼看懂，无术语堆砌 | 口语化，无行话 | 术语密集、读不懂 |
| 可行动性 actionability | 处理建议具体到"找谁、看什么、做什么" | 分步骤、可照做 | 空泛套话（"请核实"） |
| 边界合规 boundary | 不判定合规/违规/可报销，引用不超输入 | 全程无判定句、无幻觉引用 | 出现判定结论或输入外引用 |
| 完整性 completeness | 是什么/影响/处理/谁处理四要素齐全 | 四要素明确可执行 | 缺 ≥2 要素 |

总分 = 五维平均（满分 5）。**切换 prompt 版本 / 模型的准入线：总分 ≥4.0 且 边界合规 ≥4**。

## 三、双盲流程

1. 跑 `eval_explain.py --mode llm` 生成候选组（如 flash-v1 / flash-v2 / pro-v1）报告；
2. 脚本导出每样本 what/impact/action/who 纯文本（无 source 标注）→ 打乱编号；
3. 评分人独立按上表打分，记入 `评分表`（样本 id 匿名化）；
4. 汇总：两组评分人差异 >1 分的维度 → 协商或引入第三人；
5. 决策：达到准入线的候选 → 产品侧确认（用户拍板）→ 切换默认（改 PROMPT_VERSION / DEEPSEEK_MODEL）。

## 五、与自动门禁的分工

- **自动（每轮 CI）**：deterministic 门禁——模板路径结构/越权/幻觉/泄露 100%；
- **自动（改 prompt/模型时）**：llm 模式指标 + rubric 代理（actionable/readable）初筛；
- **人工（本模板）**：双盲评分 → 最终决策。代理指标高分 ≠ 人工通过，人工高分 ≠ 跳过自动门禁。
