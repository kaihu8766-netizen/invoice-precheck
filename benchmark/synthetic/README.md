# benchmark/synthetic 样本来源声明

本目录存放基准测试用合成发票 PDF。所有样本均为**虚构数据**，仅用于解析/规则/基准测试，绝不含任何真实发票。

## 样本构成

| 文件 | 票号系列 | 来源 | 说明 |
|---|---|---|---|
| synthetic_1~5.pdf | `253000000000900000xx` | `scripts/gen_synthetic_pdf.py`（确定性生成器） | 标准数电票样本 |
| synthetic_6_motor_exempt_single.pdf | `25452000000051553220` | 手工构造（2026-09 建立，仿机动车免税票样格式） | 单笔机动车免税场景；公司名/税号/金额均为虚构 |
| synthetic_7_motor_exempt_multi.pdf | `25452000000051553220` | 手工构造（同上） | 多行机动车免税场景；公司名/税号/金额均为虚构 |

## 追溯说明

- synthetic_6/7 为早期手工录入的特殊场景样本，未进入生成器代码（生成器只产标准系列）。
- 样本中的公司名（如"马鞍山精灵汽车贸易有限公司"、"精灵汽车销售（南宁）有限公司"）、税号（不完整展示 `91340500MAC...`/`91450100MA7...`）、票号、金额均为虚构，与任何真实主体无对应关系。
- 复核：RV-20260925-98（DeepSeek 证据工具模式全仓红线扫描 0 命中，其中 synthetic_6/7 经抽查确认为虚构样本）。
