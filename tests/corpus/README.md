## 使用规则

1. **脱敏纪律**：真实票样一律先脱敏再入库（名称虚构、税号打码、电话/账号/开票人删除或虚构；金额/税率/日期保留——规则验证需要）。
2. **不采集他人发票**：语料仅来自①官方公开样例 ②公开博客 dump（二次脱敏）③用户自有票样（本人/亲友同意）。
3. **合成样本分开**：`validation-week/` 合成样本测"问题形态命中/误报"，本目录测"真实结构可解析"。
4. **来源必标**：每条票样保留来源 URL 与脱敏状态（见上表）。
5. 本目录进入公开仓库（invoice-precheck 为 Public），确保不含任何可识别真实主体信息。
